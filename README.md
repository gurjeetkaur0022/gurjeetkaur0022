## 📌 Featured Projects

### 🤖 AI Autonomous Portfolio Rebalancing Platform

Production-oriented portfolio intelligence platform that monitors portfolio drift, determines when rebalancing is required, and generates optimized trades under real-world constraints.

- Built **CVXPY-based portfolio optimization** with drift, turnover, long-only, transaction-cost, and tax-aware constraints
- Implemented **threshold, calendar, and event-driven rebalancing** with strategy backtesting and performance analysis
- Developed **FastAPI REST APIs** with PostgreSQL persistence, audit trails, and automated testing
- Integrated an **LLM-powered agent layer** for portfolio analysis and client, advisor, and compliance explanations

**Tech:** Python · FastAPI · PostgreSQL · CVXPY · Pandas · NumPy · LLMs · Pytest

[View Repository →](https://github.com/gurjeetkaur0022/portfolio-intelligence-platform)

### 🎼 Scaling Laws in Symbolic Music Modeling

Research project investigating how neural language models scale when trained on large symbolic music datasets.

- Processed **178K MIDI files** into a symbolic music corpus containing approximately **143M tokens**
- Trained **Transformer and LSTM architectures** across multiple model sizes
- Analyzed relationships between model scale, training data, loss, and perplexity to study neural scaling behavior

**Tech:** Python · PyTorch · Transformers · LSTM · NumPy · Pandas

[View Repository →](https://github.com/gurjeetkaur0022/music_scaling_laws)
